# Soundscape assets

All three files are recordings from Wikimedia Commons under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). They are loaded only after the user presses **Phát âm thanh**. No third-party audio host receives a playback request.

| Bundled file | Source recording and author | Bundled version | Processing |
| --- | --- | --- | --- |
| `rain.ogg` | [Light Rain Distant Thunder July 5th 2016](https://commons.wikimedia.org/wiki/File:Light_Rain_Distant_Thunder_July_5th_2016.wav), kvgarlic | Wikimedia Commons Ogg Vorbis transcode, 1,478,897 bytes | Commons transcode from original WAV; no local cut or normalization |
| `forest.ogg` | [Toucans singing in the Amazonian Rainforest](https://commons.wikimedia.org/wiki/File:404114_felix-blume_toucans-singing-in-the-amazonian-rainforest-brazil.ogg), Felix Blume | Commons original Ogg Vorbis, 7,160,067 bytes | No local cut or normalization |
| `stream.ogg` | [Swale](https://commons.wikimedia.org/wiki/File:Swale.ogg), Ksd5 / Siddharth Patil | Commons original Ogg Vorbis, 1,092,440 bytes | No local cut or normalization |

The original author and CC0 status were checked on the linked Commons file pages on 2026-10-25. These versions are intentionally retained without local changes so the source and exact binary remain auditable. Playback is local in each browser, independent of the Camp session and server timer. No audio choice or playback event is broadcast to other members.
