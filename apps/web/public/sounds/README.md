# Soundscape assets

`rain.wav`, `forest.wav`, and `stream.wav` are original procedural recordings generated by `generate.py` for this repository. Their authors dedicate these three audio files to the public domain under CC0 1.0. They contain no third-party samples. Regenerate with `python apps/web/public/sounds/generate.py`.

Playback is local in each browser, independent of the Camp session and server timer. No audio choice or playback event is broadcast to other members.
