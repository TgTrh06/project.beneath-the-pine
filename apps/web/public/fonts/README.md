# Webfont sources

Added for the approved Nyna Coffee typography reference.

- Source page: https://nynacoffee.com/
- Font source directory: https://nynacoffee.com/wp-content/themes/nynacoffee/assets/fonts/
- SVN-Engine.woff2: display face, declared at weight 600 by the source site.
- BeVietnamPro-Regular/Medium/SemiBold/Bold.woff2: body faces, mapped to 400/500/600/700 by filename rather than the source site's inconsistent CSS declarations.
- Be Vietnam Pro upstream: https://github.com/bettergui/BeVietnamPro
- Be Vietnam Pro license: OFL-BeVietnamPro.txt, from the upstream repository.
- Pixelify Sans source: https://fonts.google.com/specimen/Pixelify+Sans
- PixelifySans-Latin/LatinExt.woff2: local display font subsets, sourced from Google Fonts static CSS and covered by OFL-PixelifySans.txt.

Files are served locally with font-display: swap. No runtime requests go to Nyna Coffee.
SVN-Engine's source page does not include a redistribution license; the URL records provenance, not a license grant.
