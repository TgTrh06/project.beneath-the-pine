# Solo forest assets

Original procedural assets for a private focus session beneath the giant Pine. The scene has a ground-seated Wanderer between the roots, a sleeping Marten immediately alongside, and one lantern. There is no campfire, gathering ring or other participants.

- `pine-solo.glb`: 1,631,368 bytes, 24 material batches. Generated by `node apps/web/scripts/build-camp-scene.mjs --solo` from the repository root. The flag writes only the solo asset; the Camp asset is retained.
- `solo-poster-{dawn,day,dusk,night}.webp`: 30–47 KB each, 1600×1000 captures of the solo scene with its generic resting Wanderer and curled Marten. No session intention, countdown, identity or private notes are embedded.

The generator shares the forest/trail/bridge geometry with Camp; the solo model replaces all gathering props. Runtime camera, character placement and lantern lighting use the solo variant of the existing lazy forest renderer. The resting poses are authored in `SoloRest.tsx`. The fixed generic character is decorative and does not receive account or private session data.

To regenerate posters, open an intercepted test solo session with reduced motion and clear weather. Select each time explicitly, hide `.focus-room__body`, `.camp-scene-settings`, `.solo-scene-status` and the `.camp-lodge::after` scrim, then capture the canvas region as WebP. Element screenshots can include overlapping HTML, so inspect the output visually before delivering it. Do not use real session data for asset generation.
