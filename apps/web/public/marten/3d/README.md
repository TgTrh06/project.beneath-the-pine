# Shared 3D Marten illustrations

Eight transparent 360 × 280 WebP renders of `MartenModel`: sit, rest, curl, side-sleep, stretch, stand, look-back and groom. Total image payload is approximately 99 KiB. These assets share one model and palette with the forest companion. No user information is embedded.

Inline messages use images, not additional WebGL canvases. Legacy illustration pose names map to these new poses. The old pixel artwork remains on disk for recovery but is no longer used by `MartenIllustration`.

Render with motion disabled, an orthographic camera and transparent background. Inspect front, side and rear views, then trim and fit into the fixed canvas without distortion. The Return greeting uses a copy of `stand.webp` at `/return/marten.webp`.
