# Identity migration baseline

`0000_identity_accounts_sessions.sql` and `meta/` were generated by Drizzle Kit from Identity-owned schemas. They introduce `account_role`, `identity_accounts` and `identity_sessions`; no historical schema is imported.

Review the target before explicitly running `pnpm --filter @beneath-the-pine/api db:migrate`. This uses the Drizzle journal and does not seed an admin. Run seed separately using server-only env as documented in [Identity](../src/modules/identity/README.md).

Do not drop account tables to roll back an application release. Preserve data and apply a forward fix. The implementation did not execute this migration against an existing database.
