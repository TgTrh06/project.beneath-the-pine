# Delivery Plan

| Phase | Outcome | Exit evidence |
| --- | --- | --- |
| P0 Foundation | Identity, ownership, privacy and contracts are stable | Two-account authorization and data-rights tests pass |
| P1 Solo return | User can start, check out and resume a seed | Core flow works through recoverable failures |
| P2 Circle pact | Private Circle can make and keep a focus pact | Invitation lifecycle and access rules pass |
| P3 Realtime reliability | Session state is correct across join/reconnect/terminal races | Server-authoritative integration tests pass |
| P4 Pilot memory | Circle milestone supports reflection without comparison | Pilot feedback finds no pressure/grind incentive |
| P5 Mobile rituals | Native client reaches return/start flow in a few actions | Native auth/notification/platform decisions reviewed |
| P6 Conditional assistance | Optional AI/personalisation adds verified value | Privacy, safety, cost and user evidence gate passes |

P0–P3 define the thesis implementation. P4+ are product roadmap and not an implied delivery commitment.
