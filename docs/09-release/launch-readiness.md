# Launch Readiness

## Private beta

- [ ] Research findings đã cập nhật scope.
- [ ] Core flow đạt usability gate.
- [ ] Legal/privacy copy được review ở mức phù hợp.
- [ ] Safety response được review.
- [ ] Test/release gates pass.
- [ ] Support và incident owner sẵn sàng.
- [ ] Beta participants có consent và biết giới hạn sản phẩm.

## Public beta bổ sung

- [ ] Terms/Privacy chính thức.
- [ ] Data processor và cross-border review.
- [ ] Production security review/threat model update.
- [ ] Capacity/cost budgets.
- [ ] Verified crisis resources theo khu vực cung cấp.
- [ ] Status/support channels công khai.
- [ ] Billing/refund policy nếu thu phí.
