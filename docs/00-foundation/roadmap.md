# Product Roadmap

## P0 — Foundation

Identity, ownership, privacy, event model, API contracts and mobile-ready backend boundary.

## P1 — Solo return loop

Return Card, activation step, solo focus session, honest check-out and Open Seed.

## P2 — Private Circle and Focus Pact

Circle membership, invitations, scheduled/immediate pact, realtime presence and synced timer.

## P3 — Circle memory

Gentle milestones and forest representation that records shared presence without scorekeeping.

## P4 — Mobile rituals

React Native + Expo, quick actions, deep links, widget and opt-in notification after API/mobile decisions.

## P5 — Conditional assistance

Pine Assistance tự train/fine-tune cho activation step, stuck recovery và Open Seed draft; personalization, audio/theme/preset hoặc host tools chỉ sau evidence, privacy, safety và cost review.

Public discovery, stranger rooms, voice/video and competitive mechanics are not roadmap commitments.
