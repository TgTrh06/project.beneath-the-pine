# Product Metrics

- **Status:** Draft for private pilot

## Primary measures

| Metric | Definition | Why it matters |
| --- | --- | --- |
| Time to start | Time from entering start flow to server-recorded session start | Measures activation friction, not productivity |
| Open Seed resume | Resumed seeds / eligible open seeds | Tests continuity after interruption |
| Pact attendance | Participants joining active pact / accepted invitations | Tests whether a structured commitment is kept |
| Repeat pact rate | Circles creating another pact after their first completed pact | Tests social pull without nagging |
| Perceived start support | Short post-session self-report | Captures felt value not inferred from timer time |

## Guardrails

- Never count minutes as work completed.
- No raw intention/Open Seed text in analytics.
- Track opt-out, cancellation, privacy concern and distraction feedback alongside engagement.
- Do not use metrics to rank people or Circle.
