# Glossary

| Term | Meaning |
| --- | --- |
| Activation step | A small, user-chosen first action for the current session |
| Open Seed | Private note describing where to restart next time |
| Solo session | A focus session belonging to one person |
| Circle | A private group of known people, limited to 2–8 members in MVP |
| Focus Pact | A scheduled or immediate mutual commitment to join a shared session |
| Focus session | Server-owned lifecycle for one timed focus interval |
| Presence | Minimal session state such as joined, active, paused or checked out |
| Circle milestone | A non-competitive record of a Circle showing up together |
