# Design System Foundations

- **Status:** Placeholder — chốt sau wireframe test

## Brand qualities

Calm, grounded, warm, restrained, trustworthy.

## Semantic tokens cần định nghĩa

- Background/surface/elevated surface.
- Text primary/secondary/muted.
- Action primary/secondary/destructive.
- Success/warning/error/info.
- Focus ring.
- Growth area colors phải đạt tương phản.

## Typography

- Ưu tiên font dễ đọc tiếng Việt.
- Body tối thiểu 16 px trên mobile.
- Line-height rộng vừa đủ; hạn chế đoạn văn dài trong flow hành động.

## Core components

- Button, IconButton, TextField, TextArea.
- Card, ActionCard, TaskRow.
- EnergyPicker, TimeEstimate.
- AIInsightCard với evidence và feedback.
- Toast/InlineAlert.
- Dialog chỉ cho thao tác cần xác nhận.
- Skeleton/Progress indicator.

## Motion

- Duration token và easing thống nhất.
- Pine animation không trì hoãn primary action.
- Reduced-motion variant là bắt buộc.
