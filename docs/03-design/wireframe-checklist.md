# Wireframe Checklist

## Screens to wireframe before code

- [ ] Now: no seed, open seed, return eligible and stuck states.
- [ ] Brain Dump composer and extraction confirmation.
- [ ] Focus Room: ready, running, paused, completed and audio unavailable.
- [ ] Open Seed creation, open and dismiss.
- [ ] Reminder settings: disabled, enabled, slot limit and save failure.
- [ ] Return ritual: Start fresh, seed available and check-in paths.
- [ ] Weekly letter: insufficient facts, evidence, feedback saved and error.
- [ ] Settings: theme/audio, consent, export/delete.

## Every screen must show

- [ ] User goal and a single obvious primary action.
- [ ] Default, focus, loading, empty, error, success and authorization-denied state where relevant.
- [ ] Mobile 320px priority layout and desktop layout; no compressed desktop-only design.
- [ ] Keyboard order, initial/return focus and semantic landmarks.
- [ ] Copy that is neutral, concrete and not productivity-shaming.
- [ ] AI/provider disclosure only where needed; no raw private content in status/copy.
- [ ] Back/cancel path that preserves safe draft input.
