# Wireframe Checklist

- Can a first-time user begin a solo session without creating a task/project?
- Is the current Open Seed visible, editable and dismissible without guilt?
- Is any private intention text visible only to its owner by default?
- Can an invitee decline or leave a pact with a neutral outcome?
- Does the active-session UI communicate reconnecting and server-derived time clearly?
- Are Circle milestones separated from current work and free of ranking?
- Do every control and terminal state work without color, sound or motion?
