# UI/UX Blueprint — Focus & Gentle Return

- **Status:** Approved design direction
- **Last updated:** 2026-08-27

## Experience promise

The interface helps a person choose one doable action now, then makes it easy to return without guilt. Calm does not mean empty: each screen is structured, legible and action-led.

## Hierarchy rules

1. State the current moment: return, seed, next action or capture.
2. Present exactly one primary action for that moment.
3. Put recovery/help actions next; move customization/history below the task.
4. Use cards only for actions or distinct information—not as default decoration.

## Screen map

| Screen | User goal | Primary action | Secondary/recovery |
|---|---|---|---|
| Now | Begin from current context | Start next action/seed | Capture, smaller step, reset |
| Capture | Empty the mind safely | Generate/select action | Save manual action, cancel |
| Focus Room | Stay with one task | Start/pause/done | Still stuck, audio/theme, exit |
| Return ritual | Re-enter safely | Start fresh/seed | Check-in, close safely |
| Progress | See useful evidence | Respond to letter | View facts, skip |
| Settings | Control space/data | Save choice | Disable reminder, export/delete |

## Content and tone

Use short concrete Vietnamese: verb + object + gentle permission. Prefer “Mình bắt đầu lại từ đây nhé” over missed-task framing. Never present completion volume, absence count or streak as a moral result.

## Retention UX

- Open Seed is optional, singular and removable.
- Reminder starts disabled and is described as a user-selected invitation, not a commitment.
- Return appears before backlog only after the 3-day rule; it offers Start fresh, open seed or check-in.
- Weekly letter shows facts/evidence before its observation; feedback is part of the same region.

## Responsive and accessibility baseline

Mobile prioritizes task/timer/primary action in the first viewport. Use semantic headings, native controls, 44px practical targets, visible focus, text alternatives for timer/audio, and reduced motion. Dark theme is independently reviewed for contrast.
