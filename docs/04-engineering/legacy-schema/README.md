# Legacy Core SQL baseline

Ba file SQL này là bản ghi tham khảo duy nhất được giữ lại từ Core backend đã xóa. Chúng mô tả `core.accounts`, `core.tasks` và `core.next_actions` để review schema Drizzle đầu tiên.

Đây không phải Drizzle migration journal và không được chạy tự động. Trước khi dùng cần so sánh với database thực tế, kiểm tra constraint/index/dữ liệu và duyệt baseline strategy theo [Drizzle Data Access](../drizzle-data-access.md).
