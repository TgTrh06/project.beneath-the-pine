# Visual QA Checklist

- [ ] Current user goal and one primary action are clear without scrolling.
- [ ] Default/loading/empty/error/success/disabled states are intentionally designed.
- [ ] Task/timer work without media, animation or theme customization.
- [ ] No nested-card clutter, decorative gradient/glow, fake metric or pressure copy.
- [ ] Controls have labels, focus state and useful target size.
- [ ] Hover/active/disabled states supplement focus and text labels; authorization-denied state reveals no protected data.
- [ ] Dialog/async focus and live feedback are correct.
- [ ] Layout tested at 320px, tablet, 200% zoom/reflow and desktop; content is reprioritized, not merely squeezed.
- [ ] Contrast, text alternatives and reduced motion are checked for all themes.
- [ ] No private content appears in status, error text or analytics-oriented UI.
