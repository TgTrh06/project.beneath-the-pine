# Retention Acceptance Matrix

| Capability | Happy path | Error/empty | Privacy/security | Accessibility |
|---|---|---|---|---|
| Open Seed | create, open, dismiss | no task/save failure | owner-only; no title in events | labelled controls, keyboard |
| Reminder | opt-in, edit, disable | no slots/delivery failure | default off; no body/title in logs | timezone label, immediate feedback |
| Return | choose fresh/seed/check-in | no seed/API fallback | no absence count/backlog | modal focus, clear exit |
| Weekly letter | show facts, submit feedback | insufficient facts | evidence only; no raw content | text not color-only |
| Focus Studio | timer + optional audio | player blocked/unavailable | URL local-only/no analytics | reduce motion, timer text |
